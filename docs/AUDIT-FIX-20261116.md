### W-04 關鍵設定與啟動檢查

- `backend/src/config/startupCheck.ts`：正式環境（`K_SERVICE` 或 `NODE_ENV=production`）啟動時，缺必要變數就印一行 WARNING，只列名稱；不會讓服務結束。已在 `index.ts` 的 `listen` callback 呼叫，並包 try/catch。測試：`__tests__/startupCheck.test.ts`。
- 非密鑰設定：`LLM_PROVIDER`、`LLM_MODEL` 移到 `deployment/production.env`，`deploy.yml` 改從那裡讀（值與原本相同）。`NODE_ENV=production` 直接寫在 `deploy.yml` 的 `env_vars`，不放 env 檔，因為該檔會被匯出到 `GITHUB_ENV`，會讓前端 `npm ci` 略過 devDependencies。
- 本輪核對時修了 `startupCheck.test.ts` 一個斷言：env 沒設 `LLM_PROVIDER` 時預設走 `openai_compatible`，缺的不會是 `GEMINI_API_KEY`，測試補上 `LLM_PROVIDER: 'gemini'`。
- 密鑰帶法（`GEMINI_API_KEY`、`HUB_ENCRYPTION_KEY`、`SCHEDULER_SECRET`）完全沒動。
- 沒有加 `CLOUD_TASKS_*`：加了會啟用 Cloud Tasks 路徑，改變線上行為。

### W-07 部署順序與檢查

- 順序改成：Firestore 規則＋索引 → Cloud Run（`no_traffic: true`、`tag: next`）→ 檢查 → 導流量 → 前端 build → Hosting。
- 檢查打的是 tag 網址 `https://next---<CLOUD_RUN_URL 的 host>`（打正式網址只會測到舊版）：`/health` 要 200（重試 5 次）、`/api/hub/me` 不帶憑證要 401（`hubAuth` 缺 Authorization 一律回 401）。
- 檢查失敗 job 就停，新版沒拿到流量，線上維持上一版，所以不另寫回滾。
- 導流量用同一個 action 再跑一次，只給 `revision_traffic: LATEST=100`。這步一定要有，不然 `no_traffic` 會讓之後每次部署都「成功」卻永遠沒上線。
- `push` 加 `paths-ignore: docs/**、**/*.md`（backend／frontend 底下只有 `frontend/README.md` 一個 md，不是執行期檔案）；`workflow_dispatch` 保留，想強制部署可手動跑。
- firebase-tools 改 `npx --yes firebase-tools@15.1.0`，和根目錄 `package.json` 同版。
- 限制：索引這步只是先送出建立請求，大型集合可能還在建，不等它建完。

### W-04：搬到 Secret Manager（我不碰雲端設定）

1. 為 `GEMINI_API_KEY`、`HUB_ENCRYPTION_KEY`、`SCHEDULER_SECRET`、`LINE_CHANNEL_SECRET`、`LINE_CHANNEL_ACCESS_TOKEN`、`INTERNAL_HARNESS_SECRET` 各建一個 secret：`gcloud secrets create NAME --project wippy-mvp`，再用 `gcloud secrets versions add NAME --data-file=-` 寫入現值。先用 `gcloud run services describe wippy-backend --region asia-east1` 確認線上現值。
2. 給 Cloud Run 執行用的服務帳號 `roles/secretmanager.secretAccessor`。
3. 在 `deploy.yml` 的 `deploy-cloudrun` 加 `secrets:` 區塊（例如 `GEMINI_API_KEY=GEMINI_API_KEY:latest`），並從 `env_vars` 移除對應的明文行。這一步等 1、2 完成後再做，否則部署會失敗；所以這次沒改。
4. `OWNER_USER_ID` 若尚未設定，用 `gcloud run services update` 設一次。
5. 部署後在 Cloud Run log 搜尋 `Missing production settings`，應該沒有這行。
